# Drum and Bass — jednoduchá ukázka stránky

Krátký popis
- Jednoduchá statická stránka o Drum'n'Bass.
- Otevřít v prohlížeči: `index.html`.

Soubory v repozitáři
- [index.html](index.html) — hlavní HTML stránka.
- [style.css](style.css) — styly pro stránku.

Důležité CSS třídy
- Nadpis: [`.nadpis1`](style.css)
- Podnadpis: [`.podnadpis`](style.css)
- Sekční nadpisy: [`.H2`](style.css)

Poznámky a doporučení
- V [index.html](index.html) je odkaz na obrázek `letitroll.webp`. Zkontrolujte, že soubor existuje ve složce projektu, jinak se obrázek nezobrazí.
- Ve [style.css](style.css) je chyba v pravidle [`.H2`](style.css): `font: size 2rem;` není platné. Doporučená oprava:
  - použít `font-size: 2rem;` místo `font: size 2rem;`.

Jak připravit na test
1. Otevřete [index.html](index.html) v prohlížeči a ověřte zobrazení.
2. Oprava chyby v [` .H2`](style.css) a případné přidání chybějícího obrázku.
3. Připravte krátké vysvětlení struktury souborů a použitých tříd pro otázky ze zkoušky.
